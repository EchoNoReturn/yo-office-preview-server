Yo-Office-Preview

Yo-Office-Preview 是一个基于 Rust 和 LibreOffice 的文档预览服务，支持将多种办公文档格式转换为 PDF 以便预览。

主要功能包括：

  • 支持多种文档格式：包括 DOCX、XLSX、PPTX 等。ODT、ODS、ODP 在逐渐适配中
  • 基于 LibreOffice 的强大转换能力。
  • 简单易用的 API 接口，方便集成到各种应用中。

环境变量配置：

  • PORT：服务监听端口，默认值为 8013。
  • OUTPUT_DIR：转换后文件的输出目录，默认值为 tmp。
  • LIBREOFFICE_PATH：LibreOffice 可执行文件的路径，例如 /Applications/LibreOffice.app/Contents/MacOS/soffice。

使用方法：

  1. 确保已安装 LibreOffice，并配置正确的 LIBREOFFICE_PATH。
  2. 设置环境变量，可以参考 .env.example 文件。
  3. 运行服务，监听指定端口。
  4. 通过 API 发送文档转换请求，获取转换后的 PDF 文件。
